# 토스증권 소액투자 추천 대시보드

실제 주문을 차단한 `PAPER` 전용 버전입니다. 샘플 추천·가상매매와 토스증권 실계좌/현재가 조회를 지원합니다.

## 실행

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env           # Windows: copy .env.example .env
uvicorn app.main:app --reload
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다.

## 토스증권 API 연결

토스증권 WTS에서 Open API 클라이언트를 만들고 실행 PC의 공인 IP를 허용한 뒤 `.env`에 입력합니다.

```env
TOSS_CLIENT_ID=발급받은_ID
TOSS_CLIENT_SECRET=발급받은_SECRET
TOSS_ACCOUNT_SEQ=
TRADING_MODE=PAPER
```

`TOSS_ACCOUNT_SEQ`가 비어 있으면 첫 번째 종합매매 계좌를 사용합니다. 화면의 **토스 연결 확인** 버튼으로 인증과 보유 주식 조회를 확인할 수 있습니다.

- `GET /api/toss/status`: 인증 및 계좌 목록 확인
- `GET /api/toss/holdings`: 실계좌 보유 주식
- `GET /api/toss/prices?symbols=005930,000660`: 실제 현재가
- `GET /api/toss/candles/005930?count=30`: 실제 일봉

## 실제 데이터 추천 지표

API 키가 설정되면 추천 화면은 후보 종목별 실제 현재가와 최근 30개 일봉을 사용합니다.

- MA5: 최근 5일 종가 평균
- MA20: 최근 20일 종가 평균
- RSI14: 최근 14일 상승·하락폭 기준
- 거래량 비율: 최신 거래량 ÷ 20일 평균 거래량
- 유동성: 최신 가격 × 최신 거래량

실시간 API 장애나 인증 실패 시 화면에는 `SAMPLE` 출처가 표시되며 실제 가격으로 오인하지 않도록 구분합니다.

## 전체 국내 종목 필터

v4는 KOSPI·KOSDAQ의 활성 보통주 전체 목록을 하루 동안 캐시하고 다음 순서로 후보를 줄입니다.

1. 시장 거래대금 상위 100종목
2. 입력 예산의 30% 이하 가격 및 거래대금 10억원 이상
3. 거래정지·정리매매 제외
4. 단기과열·투자경고·투자위험·VI 등 활성 유의사항 제외
5. 안전 후보 상위 12종목의 실제 일봉 분석
6. 지표 점수 상위 5종목 표시

화면에는 각 단계의 통과 종목 수가 표시됩니다. API `429` 응답은 `Retry-After`를 반영해 한 번 자동 재시도합니다.

## API 오류 안내

v6는 토스 API가 오류를 객체 또는 문자열로 반환하는 경우를 모두 처리합니다. 실행 PC의 공인 IP가 WTS 허용 목록에 없으면 화면에 다음 안내를 표시합니다.

```text
IP address not allowed
WTS 허용 IP를 확인하세요.
```

## 추천 이력과 가상매매 성과

v5는 같은 날짜·종목의 추천을 한 번만 저장하고 현재가 대비 수익률을 추적합니다. 가상 보유 종목은 실제 현재가로 평가하며 전량 가상매도, 평균단가, 평가손익, 실현손익, 누적수익률과 매도 승률을 표시합니다.

수수료와 세율은 증권사·시장·정책에 따라 달라질 수 있어 기본값은 0입니다. 필요하면 `.env`에서 직접 설정합니다.

```env
PAPER_INITIAL_CASH=10000000
PAPER_BUY_FEE_RATE=0
PAPER_SELL_FEE_RATE=0
PAPER_SELL_TAX_RATE=0
```

## v7 백테스트

종목코드와 초기 투자금, 손절·익절 비율, 최대 보유 거래일을 입력하면 토스 API의 최근 200개 일봉으로 전략을 검증합니다.

- `현재 종가 > MA5 > MA20`, RSI 40~65에서 매수 신호
- 신호 다음 거래일 시가에 매수한 것으로 계산
- 일중 저가가 손절가에 닿으면 손절
- 일중 고가가 익절가에 닿으면 익절
- 같은 날 손절가와 익절가에 모두 닿으면 보수적으로 손절 우선
- 최대 보유기간 도달 시 당일 종가 매도
- 수수료·세금, 총수익률, 최대낙폭(MDD), 승률 표시

백테스트 결과는 과거 데이터 기반 모의 계산이며 미래 성과를 보장하지 않습니다.

## PAPER 자동 손절·익절

서버가 실행 중일 때 설정 간격으로 가상 보유 종목을 확인합니다. 토스 국내 시장 캘린더의 정규장 세션에서만 동작하고 주말·공휴일·장외시간에는 매도하지 않습니다.

```env
PAPER_AUTO_EXIT_ENABLED=true
PAPER_STOP_LOSS_RATE=0.05
PAPER_TAKE_PROFIT_RATE=0.10
PAPER_AUTO_EXIT_INTERVAL_SECONDS=60
```

자동 매도 내역은 `AUTO_STOP_LOSS` 또는 `AUTO_TAKE_PROFIT` 사유와 함께 `paper_trades`에 저장됩니다. 이 기능은 PAPER 거래에만 적용되며 실제 계좌 주문은 생성하지 않습니다.

## v8 PAPER 자동매수

정규장 운영 중 추천 점수가 기준 이상인 종목을 위험관리 규칙 안에서 가상매수합니다. 처음 설치하거나 DB를 마이그레이션한 직후에는 안전 잠금 상태이므로 대시보드의 **자동매수 시작** 버튼을 눌러야 신규 가상매수가 시작됩니다.

```env
PAPER_AUTO_BUY_ENABLED=true
PAPER_AUTO_BUY_INTERVAL_SECONDS=900
PAPER_AUTO_BUY_BUDGET=5000000
PAPER_AUTO_BUY_MIN_SCORE=80
PAPER_MAX_POSITIONS=3
PAPER_MAX_ORDER_AMOUNT=100000
PAPER_DAILY_LOSS_LIMIT_RATE=0.03
```

- 같은 날짜·같은 종목의 자동매수 신호는 한 번만 처리
- 이미 보유한 종목은 추가 자동매수하지 않음
- 최대 3종목, 한 주문 10만원 기본 제한
- 당일 평가자산이 기준값보다 3% 이상 감소하면 신규 자동매수 중지
- 긴급정지는 신규 자동매수만 차단하고 기존 보유 종목의 자동 손절·익절은 유지
- 주말·공휴일·장외시간에는 자동매수하지 않음
- 자동매수는 `AUTO_BUY_SCORE_점수` 사유로 거래 및 신호 기록

백테스트 실행 결과는 `backtest_runs` 테이블에도 저장합니다. 화면 수익률은 `총손익 ÷ 초기 투자금`으로 다시 계산해 최종 평가금과 항상 일치시킵니다.

## v9 PAPER 안정화

v9는 실제 주문을 추가하지 않고 PAPER 자동매매의 관찰·보호·분석 기능을 완성합니다.

- 손절·익절 외에 보유 중 최고가 대비 추적 손절 지원
- 최초 추적일부터 최대 보유 달력일 도달 시 자동매도
- API 오류가 3회 연속 발생하면 신규 자동매수 중지
- 시장 운영 상태, 마지막·다음 검사 시각, 연속 오류 횟수 표시
- 후보 검색, 점수 미달, 보유 중 제외, 주문 거절, 매수·매도 이유 기록
- 오늘의 매수·매도 건수, 실현손익, 일일 수익률 보고서
- 최근 백테스트 수익률과 PAPER 누적 수익률 비교
- 위험 설정을 대시보드에서 변경하고 DB에 즉시 저장
- 전체 PAPER 거래 기록을 Excel 호환 UTF-8 CSV로 다운로드

화면에서 변경 가능한 값은 `automation_config` 테이블에 저장되며 서버를 재시작해도 유지됩니다. 환경변수는 DB가 처음 생성될 때의 기본값으로 사용합니다.

추적 손절은 현재가 폴링 시점에 관측한 최고가를 기준으로 하므로 틱 단위의 실제 장중 최고가와 차이가 날 수 있습니다. 최대 보유기간은 거래일이 아닌 달력일 기준입니다.

v9에도 실제 주문 생성·정정·취소 엔드포인트는 없습니다. 토스증권 실계좌 기능은 계속 조회 전용입니다.

### v9.1 표시 색상

한국 주식 화면 관례에 맞춰 수익·상승 숫자는 빨간색, 손실·하락 숫자는 파란색으로 표시합니다. 오류와 자동매매 중지 상태는 손익 색상과 구분해 기존 경고색을 유지합니다.

### v9.2 이동 네트워크 연결 보호

- `IP address not allowed`가 확인되면 신규 자동매수를 즉시 중지합니다.
- 화면 상단에 `WTS 허용 IP 등록 필요` 경고를 계속 표시합니다.
- 새 Wi-Fi로 이동한 경우 WTS에 현재 공인 IP를 직접 등록해야 합니다.
- `연결 복구 확인`은 기존 토큰을 폐기하고 새 토큰으로 계좌 조회까지 검증합니다.
- 복구 성공 후에도 자동매수는 자동 재개하지 않으며 사용자가 별도로 시작해야 합니다.

### v9.3 일별 매매 성과 저장

- `daily_performance` 테이블에 현금, 평가금, 일손익, 누적손익, 수익률과 매매 건수를 날짜별 저장
- 실행 중에는 5분마다 오늘의 진행 성과 갱신
- 날짜가 바뀌면 전날 성과를 자동으로 확정
- 아침에 서버를 시작했는데 전날 기록이 없으면 거래내역과 전날 종가로 자동 복원
- 대시보드에서 최근 30일 성과와 확정 여부 확인

### v9.4 자동매수 신호 종목명 표시

- `auto_signals`에 종목명을 함께 저장
- 기존 DB의 자동매수 신호는 거래·추천 이력과 토스 종목 목록에서 종목명을 보강
- PAPER 자동매매의 최근 자동매수 신호를 `회사명 종목코드` 형태로 표시

### v9.5 판단 로그 스크롤 영역

- 자동매매 판단 로그 영역 높이를 제한하고 내부 세로 스크롤 지원
- 로그 행 간격을 조금 줄여 최근 이벤트를 더 촘촘하게 표시
- 로그 데이터 저장 방식과 CSV 다운로드는 기존과 동일

### v9.6 수동 화면 갱신

- 상단에 `새로고침` 버튼 추가
- 버튼 클릭 시 추천 후보, 보유 종목 평가손익, 일별 성과, 판단 로그를 다시 조회
- 조회 중에는 중복 클릭을 막기 위해 버튼을 잠시 비활성화

### v9.7 장세 기반 자동매수 강도 조절

- 자동매수 후보군 중 MA20 위에 있는 종목 비율과 평균 추세로 장세를 판단
- 장세 양호: 설정 점수 그대로 자동매수
- 장세 보통: 자동매수 기준 점수 +5점
- 장세 약함: 자동매수 기준 점수 +10점
- 장세 방어: 신규 자동매수 보류
- 자동매매 판단 로그에 `MARKET_FILTER`를 남겨 장세 판단 근거 확인

### v9.8 1,000만원 PAPER 테스트 기본값

- 신규 DB 기준 가상 계좌 기본 잔액을 1,000만원으로 변경
- 추천 후보 검색 기본 금액을 가상 잔액의 50%인 500만원으로 변경
- 화면의 추천 금액 입력값이 `.env`의 `PAPER_AUTO_BUY_BUDGET`을 따라가도록 변경
- 기존 DB를 새 기준으로 다시 시작할 수 있는 `PAPER 초기화` 버튼 추가
- 실제 자동매수 금액은 계속 `자동매매 위험 설정`의 주문 한도를 따름

### v9.9 5분 자동 화면 갱신

- 대시보드가 5분마다 `/api/dashboard`를 다시 조회
- 추천 후보, 보유 종목 평가손익, 일별 성과, 판단 로그를 자동으로 갱신
- 수동 `새로고침` 버튼은 유지
- 자동 갱신과 수동 갱신이 겹쳐도 중복 요청이 쌓이지 않도록 보호

## 안전 설정

- `TRADING_MODE=PAPER`만 허용합니다.
- API 키가 없어도 샘플 데이터로 실행됩니다.
- 실제 주문 엔드포인트는 구현하지 않았습니다.
- 가상매수 금액은 입력 예산 및 가상 현금 한도를 넘을 수 없습니다.
